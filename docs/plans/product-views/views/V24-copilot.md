# V24 · Contextual AI sidepanel

**Entry** **KI-Copilot** or an artifact’s **KI-Review** opens the right panel over the current project route. For example, `#/project/kundenportal/doc/PRD-03` remains the document route while the panel is open. There is no separate project-context panel. Depends on V01, V03/V04 and V23. Use the other views’ read models for contextual sources and V16 for explicit HTML generation. Read the [shared contracts](../contracts.md), [groundwork intake](../groundwork.md), [shell blueprint](../../obsidian-plugin-shell-blueprint/README.md) and [documented ChatPRD research](../../../concept/Product-Engineering-UX-Qualitaetsreview.md#ki-copilot-im-produktprojekt).

### Build the flow

1. Show active project/provider, thread chooser, conversation, source selection, project instructions and composer. Opening the panel creates no thread and sends no content. In a fresh composer preselect the current artifact only when identifiable, for example the exact PBI/map/note/NFR, focused domain entity or selected trace PBI. The project overview begins without a source. An unsent composer may follow navigation until context is chosen. Keep an established conversation’s scope stable.
2. **Fragen**, **Prüfen**, **Entwerfen** and **Überarbeiten** share an explicit **Senden** action. A contextual review sets the target and mode, leaving the prompt editable. Draft kinds are Vision, JTBD, Research and PRD. Require an editable note for revision. Display exact selected sources before send. Send only the user’s input, relevant history from this thread, project instructions and selected project-local text. Source links in responses reopen their correct native views.
3. Stream an answer and let the user cancel/retry. Label the offline demo. Preserve per-project threads, source keys, instructions and unsent draft text across reload. On project/context/provider changes cancel obsolete requests and reject late response IDs. When the UI closes or the native leaf unloads, release listeners and cancel disposed work. In a narrow pane present an accessible sheet and restore focus and underlying document scroll on close.
4. Treat generated changes as proposals. Show the proposed title/Markdown and allow edits before **Übernehmen**. Creating a note uses V03/V04 and preserves source links. Updating a note requires a matching project, target and base revision; protect unsaved work in other open leaves. Detect already-applied proposals, record the outcome and open the exact note. Applying is separate from V05 Git commit and separate from Factory dispatch. Render provider Markdown without resolving arbitrary remote images or executing embedded content.

### Native integration

Extend the existing [AgentChat port](../../../../src/application/integrations/chat/index.ts), [configured service](../../../../src/application/integrations/chat/service.ts) and [abortable presentation session](../../../../src/presentation/integrations/chat-session.ts). The existing [agent-chat route](../../../../src/application/integrations/routes.ts) should lead into the same consent-guarded workspace when exposed. Assemble source keys, validated project data, proposal parsing and persistence in application/domain code. The current CLI port accepts text user/assistant messages and streams text. Serialize selected context deliberately within its supported protocol. Validate structured proposal content locally before applying. Connect V16’s explicit generation job to the same consent-guarded provider. Preview the selected prototype payload/destination, validate the returned HTML, pass it to V16’s versioned import path and retain the earlier preview on failure or cancel. For provider errors show a recoverable next action. Confirm disposal on plugin unload using the groundwork host harness. The MCP server’s published items and CLI permissions are separate from selection of chat context.

### Red-first acceptance and handoff

- With two projects sharing a doc ID, first fail the test for a scoped review of `PRD-03`. Verify zero calls on open, exactly one send with the selected sources, and no unrelated notes, file contents, imported prototype HTML or MCP token in history/payload. Test missing/deleted source, bad proposal/empty stream, no provider, error, retry and cancellation using a controlled adapter.
- Reopen a saved thread and its unsent draft. Verify no cross-project history and a late result after switching project, provider, target or opt-in cannot write. Verify the scrolling composer keeps **Abbrechen** reachable while receiving text.
- Create a linked PRD proposal once, edit/confirm a revision against matching content, then try applying to a note edited since generation. Disable replacement of the changed note and offer **Als neue Notiz speichern**. Successful revisions return the same note to **Entwurf** for review and commit. On desktop and narrow native panes check keyboard source selection, focus return and precise navigation from citations.
- Report the exact transport tested, source matrix, proposal/write result, red/green evidence and `npm run verify` exit code. Use deterministic providers for acceptance. Verify V16’s generation action with a controlled answer and compare its saved preview/export to the expected HTML. A native-model smoke test can be recorded separately when explicitly authorized.
