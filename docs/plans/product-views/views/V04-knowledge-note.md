# V04 · Knowledge note, editor and references

**Outcome.** Read and edit a real project note, link vault content and move from a problem to evidence and requirements directly from its JTBD page.

**Inputs.** Requires the V01 navigation guard, V03 note identity, templates and creation command, the delivered [note services](../groundwork.md), [shell blueprint](../../obsidian-plugin-shell-blueprint/README.md) and [shared contracts](../contracts.md). Open the [clickdummy](../../../concept/Product-Engineering-Clickdummy-Story-Maps.html) at `#/project/kundenportal/doc/JOB-12`, `VIS-01`, `PRD-03` and `ENT-01` under the same route. Inspect `documentView`, `documentStateMeta`, `noteActions`, `foundationNext`, `foundationRelations`, `richEditor`, `vaultRelationsSection` and `insertVaultAtCaret`.

## Implement this slice

- Give the title the available width. Place **Notiz bearbeiten** next to **Notizaktionen** (export and opt-in KI-Review). Keep ID, assignment, approval and actionable Git state on the quieter metadata row. Inside the note put contextual actions such as **Im Domainmodel öffnen** and scope assignment next to their content. Preserve approval and Markdown export. Support **Inhalt**, **Bearbeiten**, **Verknüpfungen** and **Git History**, keyboard focus, accessible action menus and a narrow leaf without clipped controls or a second separator above a card.
- Use the final note-store/codec for title, body, typed fields and explicit save. Render vault Markdown through the host with the correct source path and component lifetime. In the editable buffer retain the underlying Markdown. Preserve formatting controls, Markdown preview, pastes, selection and back navigation. Give the editor an accessible name without the duplicate **Inhalt** title bar. Expose unsaved, saved/uncommitted, clean and externally conflicting states separately. Compare expected revision on write and retain the buffer on conflict or failure.
- Support typed `[[Note]]`, `[[path/note#heading|alias]]` and `![[path/image.png]]`. Use Obsidian link generation/resolution and a vault-backed file picker for notes, attachments and images. Insert at the preserved caret or selection. **Verknüpfungen → Verweis hinzufügen** manages additional refs, deduplicates resolved targets and shows source/backlinks. Query metadata for candidates, render or open selected content through the host, distinguish same-basename files by path, and keep unresolved links readable/editable. One vault may contain attachments outside the project folder. Product relations remain project-scoped.
- Provide **Research starten** and **PRD ableiten** from a JTBD. Submit V03’s draft with the originating job preselected and visible. Allow further project jobs and the product vision on a PRD. Show both directions on note reload, even in a project with zero PBIs. Allow a job to start/open the vision, a vision to start a PRD, and a PRD to start a map through the map creation owner. Keep direct sources separate from related PBI artifacts and list each source once.

## Test first and finish

1. Start from a JTBD in an empty backlog. Create research, save, reload, return via the backlink, derive two PRDs and choose a second job and vision on one. Cancel or switch projects in a stale creation dialog and verify no extra file or link. Port [job derivation](../../../concept/tests/test_job_research.py) and [product flow](../../../concept/tests/test_product_flow.py).
2. Select text, insert an aliased vault link, type a heading link and pick an image. Save, edit again, export and reload. Assert the original Markdown, resolved navigation and deduplicated refs. Verify ambiguity, unsupported file types, missing targets and unrelated external file edits. Use [wikilinks](../../../concept/tests/test_wikilinks.py), [picker](../../../concept/tests/test_vault_picker.py) and [vault references](../../../concept/tests/test_vault_references.py). Exercise real host link resolution in a disposable vault.
3. Hit Back from a dirty editor, cancel and continue typing. Save or discard deliberately; preserve focus and handle a concurrently changed note. After V05 lands port [commit actions](../../../concept/tests/test_note_commit_actions.py) including compare, first commit and save-then-commit. Capture narrow split/popout evidence for the header and menu.

Return exact route, creation-origin and related-section extension points to story maps, domain entities, deliverables, Git and AI. A later agent can add a related section or action without introducing another renderer or editor. Report red-to-green evidence and the verify exit code.
